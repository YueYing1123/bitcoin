# 数据构建资产索引

## 代码

- `code/round-2-20260516-063920/ensemble_els/`：多模型裁判文本结构化抽取包，含 LLM 客户端、字段 schema、prompt、投票融合和 CLI。
- `code/legacy/analyze_all.do`：旧项目主 Stata 分析脚本，负责 JSONL 扁平化、变量清洗、描述统计、回归、DID 和事件研究产物。
- `code/legacy/analyze_region_cause.do`：地区与案由分布分析脚本。
- `code/legacy/analyze_amount_diagnostics.do`：金额字段诊断脚本。
- `code/legacy/analyze_civil_amount_scenarios.do`：民商事金额场景回归脚本。
- `code/legacy/regexandevlauate.py`：金额和合同效力的正则抽取/评估辅助脚本。

## 数据

- `data/raw/data-index.xlsx`、`data/raw/data-index-copy.xlsx`：原始索引表。
- `data/raw/data-index.json`：索引 JSON。
- `data/raw/data-texts.json`：原始文本 JSON。
- `data/processed/extraction/final_all.jsonl`：旧项目最终结构化抽取结果。
- `data/processed/extraction/data-index_amount_regex.json`、`data/processed/extraction/data-texts_amount_regex.json`：正则金额抽取结果。
- `data/processed/analysis_data/final_all_flat.csv`、`data/processed/analysis_data/final_all_flat.dta`：旧项目扁平化后的分析数据。
- `data/external/fields.yaml`：旧项目字段抽取与扁平化口径。

## 结果

- `result/round-2-20260516-063920/tables/`：描述统计、Logit、DID、事件研究、活动类型和交叉表。
- `result/round-2-20260516-063920/figures/`：年度案件数、合同无效率、活动类型、2017/2021 事件研究图。
- `result/round-2-20260516-063920/region_cause/`：地区、案由及地区-案由关系的表格、图和日志。
- `result/round-2-20260516-063920/diagnostics/`：金额字段诊断结果。
- `result/round-2-20260516-063920/civil_amount_scenarios/`：民商事金额场景扩展结果。

## 使用提醒

- 旧项目主题偏数字货币裁判文本，新研究若扩大到其他法学数据，需要重新确认字段口径和数据生成过程。
- 旧分析报告明确提示 `total_amount_cny` 不可直接使用，金额研究需先修复或重建金额变量。
- `data/audit/` 体量不大但文件较多，主要用于追溯模型原始输出和一致性投票，不应直接作为统计分析主表。
