# round-3 主数据集合并分析

## 是否已有主数据集

本轮检查发现已有 `data/processed/analysis_data/final_all_flat.csv`，但它不能完全作为后续研究主数据集。原因是该表未完整保留：

- `final_all.jsonl` 顶层 LLM 金额 `case_amount`
- `final_fields.virtual_currency_info.total_amount_cny` 的原始字段
- 全文正则金额候选数组
- 索引正则金额结果
- 原始索引表字段
- 原始全文的存在性、长度、哈希和摘录
- 金额来源与兜底标记

因此本轮新建 `data/processed/master/master_dataset.csv` 作为统一主数据集。

## 合并键

全部数据源以 `doc_id` 合并。原始索引表中的键为 `可唯一识别id`，合并时统一映射为 `doc_id`。

## 输入数据

- `data/processed/analysis_data/final_all_flat.csv`
- `data/processed/extraction/final_all.jsonl`
- `data/processed/extraction/data-texts_amount_regex.json`
- `data/processed/extraction/data-index_amount_regex.json`
- `data/raw/data-index.json`
- `data/raw/data-texts.json`

## 金额字段处理

主表保留多个金额口径，不互相覆盖：

- `llm_top_case_amount_cny`：`final_all.jsonl` 顶层 `case_amount`
- `llm_total_amount_cny`：`final_fields.virtual_currency_info.total_amount_cny`
- `amount_flat_case_cny`：旧扁平表 `case_amount`
- `amount_flat_total_cny`：旧扁平表 `total_amount_cny`
- `regex_text_amounts_json`：全文正则匹配候选列表
- `regex_text_amount_max_cny` 等：全文正则统计字段
- `regex_index_amount_max_cny` 等：索引正则统计字段
- `amount_master_cny`：默认研究金额变量

`amount_master_cny` 的优先级为：LLM 顶层 `case_amount`、LLM 字段 `virtual_currency_info.total_amount_cny`、旧扁平表 `case_amount`、旧扁平表 `total_amount_cny`、全文正则最大值、索引正则最大值。

## 风险与使用提醒

- `llm_total_amount_cny` 当前为 0 个非空值，说明旧 JSONL 的 `virtual_currency_info.total_amount_cny` 字段不可直接作为金额来源。
- `llm_top_case_amount_cny` 与全文正则候选不一致标记为 1,720 行，金额研究需结合 `amount_master_source`、`amount_llm_regex_text_conflict` 和候选列表做稳健性检查。
- 主表不嵌入全文，全文仍以 `data/raw/data-texts.json` 为权威来源，通过 `doc_id` 关联。
