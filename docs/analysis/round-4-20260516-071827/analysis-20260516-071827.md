## 3. 金额变量检验

金额变量不是缺数据问题。主金额变量覆盖非常高：

- `amount_master_cny` 非空 12,102
- `llm_top_case_amount_cny` 非空 11,684
- `regex_text_amount_max_cny` 非空 12,100
- 主金额来源：LLM 顶层 `case_amount` 11,684 条，全文正则最大金额兜底 418 条，缺失 33 条

LLM 金额与正则金额存在较强但不完全一致的关系：

- LLM 金额出现在正则候选金额列表中的比例：85.3%
- 冲突标记比例：14.7%
- 原始金额 Spearman 相关：0.704
- 对数金额 Pearson 相关：0.680
- 金额对齐 OLS：`log_llm_case_amount ~ log_regex_text_max + controls` 中，`log_regex_text_max` 系数 0.566，p < 0.001，R2 = 0.568，N = 11,680

金额分位的描述统计显示高金额组有信号：

- Q1 无效率 45.6%
- Q2 无效率 42.7%
- Q3 无效率 47.3%
- Q4 无效率 60.5%

但进入控制变量后，金额效应不稳定：

- 主 LPM：`log_amount_master` 系数 0.0025，p = 0.429，N = 5,709
- 加入活动类型和年份固定效应后：`log_amount_master` 系数 0.0033，p = 0.272
- 使用 LLM 金额：`log_llm_case_amount` 系数 0.0036，p = 0.273
- 使用正则最大金额：`log_regex_text_max` 系数 -0.0120，p < 0.001
- 严格因变量口径：`log_amount_master` 系数 0.0038，p = 0.232
- 金额分位控制规格中，Q4 相对基准不显著；民商事子样本中 Q4 反而显著负向
- 低维 Logit 中 `log_amount_master` 显著为正，但高维类别控制下 Logit 存在奇异矩阵问题，说明该结果对控制结构敏感

判断：金额变量必须保留，而且适合做机制、异质性、稳健性和数据质量讨论。但目前不能把“金额规模越大越容易被认定无效”直接作为主结论；该关系明显受案由、刑民结构、活动类型和金额口径影响。

## 4. 地区变量检验

地区问题已经解决到可建模程度。脚本使用两层映射：

1. 优先用 `cpca` 从 `court_name` / `index_court_name` 识别省、市、区、adcode
2. 对未映射样本，用案号中的省级简称兜底

映射结果：

- `cpca_court`：12,019 条
- `case_number_prefix`：84 条
- `unmapped`：32 条
- 省份覆盖率：99.7%
- 城市覆盖率：94.8%

地区描述统计有明显差异：

- 东部无效率 44.5%
- 中部无效率 54.9%
- 西部无效率 49.7%
- 东北无效率 40.1%
- 北京无效率 25.2%
- 广东无效率 39.0%
- 山东无效率 61.9%
- 湖南无效率 61.0%
- 河南无效率 58.8%

地区回归结果：

- Big4 地区（北京、上海、广东、浙江）LPM 系数 -0.0824，p < 0.001，N = 5,696
- 解释：在控制金额、金额质量标记、法院层级和案由组后，Big4 地区案件被归入非完全有效的概率约低 8.2 个百分点

判断：地区变量可以进入下一轮研究。它不应再被视为不可用字段。更稳妥的用法是先做地区异质性和司法市场/监管环境差异，而不是马上把地区作为因果主变量。

## 5. 政策时间与合同效力

时间断点仍然是目前最稳定的主线。

描述统计：

- 2017 前合同非完全有效率：25.8%，2017 后：47.9%
- 2021 前合同非完全有效率：44.1%，2021 后：49.6%

回归结果：

- 主 LPM 中 `post2021` 系数 0.0767，p < 0.001，N = 5,709
- 加入高金额交互后，`post2021` 仍为 0.0770，p < 0.001
- 加入 Q4 金额交互后，`post2021` 为 0.0800，p < 0.001
- 民商事子样本中，`post2021` 为 0.0945，p < 0.001
- 严格因变量口径下，`post2021` 为 0.0784，p < 0.001

判断：2021 政策后法院对虚拟货币相关合同的非完全有效判断显著上升，是当前最稳的主线。金额和地区可以作为这条主线下的异质性与机制变量。

## 6. 活动类型与案由结构

活动类型和案由差异非常大，是解释金额不稳定的重要原因。

活动类型无效率：

- 发币/ICO：88.2%
- 场外交易(OTC)：73.6%
- 虚拟货币交易：66.7%
- 交易所炒币：62.0%
- 委托理财/代投：54.4%
- 挖矿：44.4%
- 虚拟货币借贷：32.4%

案由层面：

- 民间借贷纠纷：35.5%
- 合同纠纷：49.0%
- 不当得利纠纷：76.9%
- 委托理财合同纠纷：63.9%
- 网络服务合同纠纷：8.0%
- 多个刑事罪名下合同效力字段一旦出现，几乎全部为非完全有效

判断：后续建模必须区分民商事与刑事样本，并将活动类型、案由组作为核心控制或分组维度。否则金额系数会吸收活动类型和案由结构。

## 7. 当前最优研究方向

本轮实际统计与回归后，最优研究方向应调整为：

**虚拟货币司法裁判中政策冲击、交易类型与合同效力认定的实证研究：兼论金额规模与地区差异。**

理由：

1. 因变量具有明确法学含义：合同有效、无效、未成立、部分有效/无效等。
2. 2021 政策后效应在多种规格中稳定为正，且民商事样本更强。
3. 金额数据可用且覆盖高，但金额效应受口径和控制变量影响，适合机制与异质性，不适合作为单独主线。
4. 地区变量已经可用，Big4 地区差异显著，可作为司法环境或地区监管差异维度。
5. 活动类型和案由结构差异足够大，能支撑有法学解释力的类型化分析。

下一轮建议：

1. 只在民商事样本中重建主回归，刑事样本改作对照或排除。
2. 将活动类型压缩为可解释的法学类型：投资/理财、交易/OTC、借贷、挖矿、技术服务、ICO/发币、其他。
3. 设计 2021 政策前后事件研究或分年份趋势图。
4. 对金额使用三套口径并列：主金额、LLM 金额、正则最大金额；同时保留冲突标记。
5. 地区使用省份、宏观区域、Big4 三层口径，不直接使用原始空 `region` 字段。
