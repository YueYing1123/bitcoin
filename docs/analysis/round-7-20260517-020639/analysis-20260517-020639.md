# Round 7 Analysis

## 主数据集字段

当前主数据集为 `data/processed/master/master_dataset.csv`，金额相关字段包括：

- `case_amount`
- `llm_top_case_amount_raw`
- `llm_top_case_amount_cny`
- `llm_total_amount_cny_raw`
- `llm_total_amount_cny`
- `amount_master_cny`
- `amount_master_source`
- `amount_master_is_regex_fallback`
- `amount_flat_case_cny`
- `amount_flat_total_cny`

主数据集生成脚本 `code/round-3-20260516-070718/build_master_dataset.py` 明确从 `final_all.jsonl` 顶层 `case_amount` 读取 LLM 金额，并将其保存为 `llm_top_case_amount_cny`。`amount_master_cny` 的第一优先来源也是该顶层 `case_amount`。

## 提示词与字段配置

基础 LLM 抽取工作流位于旧目录 `数据构建/ensemble_els/`，迁移副本位于 `code/round-2-20260516-063920/ensemble_els/`。`ensemble_els/llm/base.py` 固定加载 `prompts/extract_cn.jinja2`，因此基础抽取提示词应以该文件为准。

旧字段配置 `数据构建/docs/fields.yaml` 包含 `virtual_currency_info.total_amount_cny`，但旧提示词中金额部分是 `plaintiff_claimed_cny` 和 `court_recognized_cny` 的拆分口径，二者与当前主数据集的 `case_amount` / `amount_master_cny` 口径不一致。

## case_amount 溯源

在 `数据构建` 与 `newstudy` 中检索 `case_amount` 后，未发现独立提示词、schema 或抽取脚本定义该字段。它只出现在 `final_all.jsonl`、旧分析脚本、主数据集合并脚本、规格检验脚本和报告中。

因此可确认：

- 基础法律字段的历史提示词是 `extract_cn.jinja2`。
- `case_amount` 原始提示词没有随现有底稿迁移或保存。
- 需要基于旧提示词和当前主数据集字段重构 `case_amount` 抽取说明，避免继续使用 `plaintiff_claimed_cny` / `court_recognized_cny`。

## 处理结果

已将整合后的提示词保存为 `docs/legacy/master_prompt.md`。该文件明确记录了溯源结论，并提供了以顶层 `case_amount` 为主金额字段的重构版提示词。
