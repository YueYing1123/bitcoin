# Round 8 Analysis

## 设计

本轮把 DeepSeek 的重新抽取结果作为标准答案，用现有主数据集字段作为被评估预测值。评价方向不能反过来。

脚本 `code/round-8-20260517-031538/deepseek_compare_eval.py` 完成两件事：

1. 随机、不重复地抽取主数据集中的判决书全文，调用 SiliconFlow `deepseek-ai/DeepSeek-V4-Flash`，将正常 JSON 输出追加到 `data/processed/master/compare.jsonl`。
2. 将 `compare.jsonl` 作为 gold，读取 `data/processed/master/master_dataset.csv` 中对应字段作为 prediction，计算每个字段的 TP、FP、FN、precision、recall、F1，以及总体 micro/macro F1。

## 评分规则

标量字段：gold 与 prediction 都为空时不计入 TP；gold 非空且相等记 TP；gold 非空但 prediction 为空记 FN；gold 与 prediction 均非空但不相等记 FP 和 FN；gold 为空但 prediction 非空记 FP。

列表字段：按规范化后的集合做元素级 TP、FP、FN。

规范化包括：数字去掉千分位逗号并按 Decimal 比较；日期统一为 `YYYY-MM-DD`；布尔值统一为 true/false；文本去空白、统一中英文括号和常见标点。
