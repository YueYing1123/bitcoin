# round-1 初始化计划

## 目标

在 `newstudy` 下建立一个可承接法学数据分析论文项目的基础工作区，整合 `memory-1.md` 与 `MEMORY-2.md` 的长期约定，并将原先偏向特定数据源的表述泛化为通用法学数据与文本分析规则。

## 边界

- 不移动、不删除上级目录中的历史文件。
- 不预设项目一定包含判决书数据，也不预设一定存在某个固定原始数据目录。
- 本轮只做初始化，不进行数据清洗、统计分析或建模。

## 执行步骤

1. 阅读两个 memory 文件，提取工作流、轮次目录、代码/结果分离、数据治理、Git/Gitee、环境约定。
2. 生成整合版 `MEMORY.md`。
3. 创建轮次化目录、legacy 目录和通用数据项目目录。
4. 写入本轮 plan、analysis、report 三类记录文件。
5. 检查目录和关键文件是否存在。

## 验收口径

- `newstudy/MEMORY.md` 存在，且内容为通用法学数据分析项目规则。
- `docs/plan`、`docs/analysis`、`docs/report`、`code`、`result` 均有 `round-1-20260516-062855` 轮次目录。
- `docs/legacy`、`code/legacy`、`result/legacy` 存在。
- `data/raw`、`data/interim`、`data/processed`、`data/external`、`data/audit`、`config`、`references` 存在。

## 风险

- 后续实际数据源和论文主题尚未确定，当前目录只能提供通用骨架。
- Git/Gitee 同步规则已写入 memory，但本轮未主动初始化或推送仓库，避免对用户现有版本控制状态作过度假设。
