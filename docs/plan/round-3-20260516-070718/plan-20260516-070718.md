# round-3 主数据集合并计划

## 目标

生成一个后续研究统一使用的主数据集，合并旧扁平分析表、LLM 最终抽取结果、LLM 金额字段、正则匹配金额、原始索引字段和原始文本审计信息。

## 判断

当前已有 `data/processed/analysis_data/final_all_flat.csv`，但它不是完整主数据集：它包含部分扁平变量和部分金额字段，但没有完整保留 LLM 顶层金额、LLM 原始金额字段、全文正则金额候选数组、索引正则金额、原始索引字段和来源标记。因此本轮需要新建主数据集。

## 输入

- `data/processed/analysis_data/final_all_flat.csv`
- `data/processed/extraction/final_all.jsonl`
- `data/processed/extraction/data-texts_amount_regex.json`
- `data/processed/extraction/data-index_amount_regex.json`
- `data/raw/data-index.json`
- `data/raw/data-texts.json`

## 输出

- `data/processed/master/master_dataset.csv`
- `data/processed/master/master_dataset.jsonl`
- `data/processed/master/master_dataset_dictionary.csv`
- `data/processed/master/master_dataset_audit.json`

同时保留带时间戳的版本，避免覆盖旧口径。

## 原则

- 以 `doc_id` 为主键合并所有来源。
- 原始全文不直接嵌入主表，只保留全文长度、哈希和短摘录；全文仍以 `data/raw/data-texts.json` 为准。
- 金额字段不互相覆盖，分别保留 LLM 金额、正则金额和最终推荐金额。
- `amount_master_cny` 的优先级为：LLM 顶层 `case_amount`、LLM 字段 `virtual_currency_info.total_amount_cny`、旧扁平表 `case_amount`、旧扁平表 `total_amount_cny`、全文正则最大值、索引正则最大值。
