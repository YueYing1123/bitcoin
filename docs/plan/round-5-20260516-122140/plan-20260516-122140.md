# round-5 研究执行计划

## 研究主题

虚拟货币司法裁判中政策冲击、交易类型与合同效力认定的实证研究：兼论金额规模与地区差异。

## 核心目标

1. 以民商事样本为主样本，刑事样本作为对照或审计对象。
2. 构造可解释的交易类型压缩变量：投资/理财、交易/OTC、借贷、挖矿、技术服务、ICO/发币、其他/未分类。
3. 围绕 2021 政策节点做描述统计、事件研究和主回归。
4. 并列检验金额三种口径：主金额、LLM 金额、正则最大金额。
5. 检验地区差异：省份、宏观区域、Big4。

## 主要输出

- 派生论文分析数据：`result/round-5-20260516-122140/paper_analysis_dataset.csv`
- 描述统计表：`result/round-5-20260516-122140/descriptive_tables.xlsx`
- 回归主表：`result/round-5-20260516-122140/regression_main.csv`
- 事件研究结果：`result/round-5-20260516-122140/event_study.csv`
- 图形：`result/round-5-20260516-122140/figures/`
- 本轮报告：`docs/report/round-5-20260516-122140/report-20260516-122140.md`

## 验收标准

- 脚本可从主数据或 round-4 派生数据一键复现。
- 民商事主样本、交易类型、金额口径、地区口径均有明确字段。
- 至少包含：政策主效应、交易类型差异、金额异质性、地区异质性、事件研究。
- 所有关键回归报告样本量、因变量均值、系数、稳健标准误和 p 值。
