# Round 8 Plan

## 任务

使用 SiliconFlow 上的 `deepseek-ai/DeepSeek-V4-Flash`，温度为 0，按照 TPM 2,000,000、RPM 500 的限制，从主数据集中随机抽取约 1% 的判决书全文重新抽取结构化 JSON，并将该结果作为标准答案 `data/processed/master/compare.jsonl`。随后以现有 `master_dataset.csv` 为被评估对象，计算字段级与总体 F1。

## 关键口径

- DeepSeek 输出是 gold。
- `master_dataset.csv` 是 prediction。
- 正常输出目标数为 `ceil(12135 * 0.01) = 122`。
- API 安全拒绝样本跳过，并继续随机抽取不重复样本，直到 gold 正常输出数达到 122。
- 数字比较会忽略逗号、整数/小数表示差异；空值、日期、布尔值和列表也做规范化。
