# Round 11 研究结果报告

本轮工作做了两件事：第一，基于 `master_dataset_dsv4.csv` 重新整合主数据，并把旧主数据、金额字段和相关控制变量合并到统一分析底稿；第二，完全改用 Python 重跑规格检验、稳健性检验和事件研究，确认当前最值得推进的研究主线。

## 1. 本轮研究在回答什么问题

这轮不是单纯做描述统计，而是想回答一个更具体的问题：虚拟货币相关司法裁判中，**政策冲击、交易类型、金额规模和地区差异**，到底谁更能解释法院对合同效力的认定变化。

简单说：
- 政策冲击看的是时间点变化，尤其是 2021 年前后；
- 交易类型看的是案件到底是投资、借贷、买卖、挖矿，还是技术服务；
- 金额规模看的是案件涉案金额大不大；
- 地区差异看的是法院所在地区是否存在系统性不同。

## 4. 模型怎么设定

这一轮用的是 Python + `statsmodels` 的回归框架。因为研究对象是二元司法结果，所以结果可以理解成“某种裁判结果出现概率的变化”。

模型里几个最关键的变量是：

- `post2017`：2017 年政策基准冲击
- `post2021`：2021 年政策冲击
- `log_amount_master`：主金额取对数
- `amount_llm_regex_conflict_flag`：LLM 金额与正则金额不一致的标记
- `transaction types`：压缩后的交易类型
- `region_big4`：大区分类
- `strict DV`：更严格的合同效力因变量
- `event study`：围绕 2021 年做动态检验，2020 年作基准年

## 5. 主要回归结果

### 5.1 政策冲击是稳定存在的

在基础模型里，`post2021` 一直显著为正，说明 2021 年前后法院在合同效力认定上确实出现了系统性变化。

| 模型 | 关键结果 | R² |
| --- | --- | ---: |
| `m1_policy_baseline` | `post2021 = 0.0850`，显著 | 0.1341 |
| `m2_transaction_types` | `post2021 = 0.0815`，显著 | 0.1949 |
| `m3_policy_by_transaction` | `post2021 = 0.0653`，显著 | 0.2022 |
| `m11_strict_dv` | `post2021 = 0.0850`，显著 | 0.1966 |
| `m12_event_study` | `post2021 = 0.0815`，显著 | 0.2038 |

这说明 2021 政策冲击不是偶然噪声，而是一个可以重复观察到的主效应。

### 5.2 交易类型带来的解释力最大

和只放金额变量相比，一旦把交易类型放进去，模型解释力明显上升：

- 基础模型 `R² = 0.1341`
- 加入交易类型后 `R² = 0.1949`
- 再加入交易类型异质性后 `R² = 0.2022`

这意味着，**交易类型不是边角变量，而是最重要的结构性解释变量之一**。从结果上看，它比单纯金额更能解释裁判结果差异。

### 5.3 金额有用，但更适合做控制和机制

金额在简单模型里是显著的，但它的作用没有交易类型稳定：

- `log_amount_master` 在基础模型里为负且显著；
- 一旦加入交易类型，金额系数就弱化，甚至不再稳健显著；
- 改成金额分位数、LLM 金额、正则金额后，主结论基本不变。

这说明金额能用，但它更像一个控制变量或机制变量，而不是整篇文章最强的主线。

### 5.4 地区有差异，但不是主轴

加入 `region_big4` 后，地区变量显著，说明不同地区的裁判环境确实存在系统差异：

- `region_big4` 在相关模型里显著为负；
- `post2021:region_big4` 交互项为正且显著；
- 但地区加入后的解释力增量，小于交易类型带来的增量。

所以地区值得写，但更适合放在异质性分析里，不适合顶替政策冲击和交易类型成为主线。

### 5.5 稳健性检验是过关的

严格因变量模型 `m11_strict_dv` 仍然支持主结论：

- `post2021 = 0.0850`，高度显著
- `log_amount_master` 不稳健
- `amount_llm_regex_conflict_flag` 仍显著

事件研究 `m12_event_study` 也说明 2021 前后变化不是单点跳跃，而是有连续的时间结构。

## 6. 本轮可以怎么理解

如果把这轮结果压缩成一句话，就是：

**2021 年政策冲击是真实存在的，交易类型是最强解释变量，金额和地区更适合做机制、控制和异质性。**

这也解释了为什么目前最有希望的主方向仍然是：

**虚拟货币司法裁判中政策冲击、交易类型与合同效力认定的实证研究：兼论金额规模与地区差异**

## 7. 对后续写作的直接启发

后面写论文时，可以按这个顺序推进：

1. 先讲政策冲击，说明 2021 前后司法态度发生变化；
2. 再讲交易类型，说明不同交易结构对应不同裁判结果；
3. 再讲金额和地区，作为机制或异质性展开；
4. 最后用严格因变量和事件研究做稳健性收尾。
