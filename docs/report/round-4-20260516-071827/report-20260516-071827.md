## 核心发现

金额不是不可用。主金额覆盖 12,102/12,135，LLM 金额覆盖 11,684，正则最大金额覆盖 12,100。LLM 金额出现在正则候选列表中的比例为 85.3%，冲突比例为 14.7%。金额对齐回归中 `log_regex_text_max` 对 `log_llm_case_amount` 的系数为 0.566，p < 0.001，R2 = 0.568。

但金额作为主解释变量目前不稳。主 LPM 中 `log_amount_master` 系数 0.0025，p = 0.429；加入活动类型和年份后仍不显著；LLM 金额也不显著。正则最大金额显著为负，说明金额口径会改变结论。金额应保留为机制、异质性和稳健性变量。

地区变量已经可用。通过 `cpca` 识别法院名称，并用案号省级简称兜底后，省份覆盖 12,103 条，覆盖率 99.7%。Big4 地区（北京、上海、广东、浙江）在控制金额、金额质量、法院层级和案由后，合同非完全有效概率低约 8.2 个百分点，p < 0.001。

当前最稳主线仍是政策冲击与合同效力。`post2021` 在主 LPM 中系数 0.0767，p < 0.001；民商事样本中为 0.0945，p < 0.001；严格因变量口径下为 0.0784，p < 0.001。

## 研究方向判断

建议将下一阶段主方向定为：

**虚拟货币司法裁判中政策冲击、交易类型与合同效力认定的实证研究：兼论金额规模与地区差异。**

这一路径能同时吸收用户强调的金额和地区变量，但不把目前不稳定的金额线性效应强行作为核心结论。

## 遗留问题

- `contract_validity` 仅覆盖 47.1%，后续应优先扩大或复核合同效力抽取。
- 刑事样本中合同效力字段一旦出现几乎全为非完全有效，下一轮主回归应优先限定民商事样本。
- Logit 在高维类别控制下存在奇异矩阵，本轮主解释以稳健标准误 LPM 为准；低维 Logit 仅作为参考。
