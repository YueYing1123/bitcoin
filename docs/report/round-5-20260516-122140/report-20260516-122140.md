## 主要结论

主样本为 2014-2024 年民商事案件，N=5,160，合同非完全有效率 42.1%。刑事样本仅作参考，因为合同效力字段一旦出现几乎全部为非完全有效。

2021 政策冲击效应稳定存在：

- 基础模型：`post2021` = 0.0866，p<0.001
- 加入交易类型：`post2021` = 0.1107，p<0.001
- LLM 金额口径：`post2021` = 0.1122，p<0.001
- 正则金额口径：`post2021` = 0.1108，p<0.001
- 严格因变量：`post2021` = 0.1115，p<0.001

交易类型是最强解释维度。以借贷为基准：

- ICO/发币：+0.550，p<0.001
- 投资/理财：+0.214，p<0.001
- 交易/买卖：+0.184，p<0.001
- 挖矿：+0.128，p<0.001
- 技术服务：-0.094，p=0.024

政策效应也按交易类型分化。2021 后效应最大的是挖矿、投资/理财、交易/买卖；ICO/发币本身已高度无效化，政策后的边际增量较低。

金额变量保留为控制和稳健性变量。连续主金额在加入交易类型后不显著；LLM 金额不显著；正则金额显著为负；Q4 高金额组也不是正向主效应。不能把“金额越大越容易无效”作为当前主结论。

地区变量可用并有水平差异。Big4 地区非完全有效概率低约 5.3 个百分点，p<0.001；但 Big4 与 2021 政策交互不显著。地区适合作为司法环境差异与稳健性分析。
