# round-6 研究结果报告（初学者版）

本轮不是重新跑一遍统计，而是把 round-5 的结果整理成一份能直接读懂的研究报告。你可以把它理解为：模型已经跑完了，这一轮要做的是把“数据告诉了我们什么”讲清楚。

## 1. 研究问题

本文研究的是：在虚拟货币司法裁判中，政策变化、交易类型、金额规模和地区差异，是否会影响法院对合同效力的判断。

这里最重要的因变量是 `contract_invalid`。它不是“合同好不好”的主观判断，而是把裁判书中的不同表述统一成一个二元变量：

- `0` 表示完全有效。
- `1` 表示无效、未成立、不成立、部分无效、部分有效、可撤销等非完全有效状态。

这样做的好处是，原本很分散的法官表述，可以变成可以统计的结果。

## 2. 先弄懂几个概念

### 2.1 政策冲击

`post2021` 代表 2021 年及以后。我们把 2021 视为一个核心政策节点，观察政策之后法院对虚拟货币相关合同的态度是否更严格。

### 2.2 交易类型

原始数据里的 `activity_type` 和 `index_case_cause` 比较碎，所以本轮把它们压缩成更容易解释的类别：

- 借贷
- 投资/理财
- 交易/买卖
- ICO/发币
- 挖矿
- 技术服务
- 其他民商事
- 其他/未分类
- 未分类

这里把“借贷”作为基准组，是因为它在样本里很常见，也比较容易理解。

### 2.3 金额变量

金额不是单一来源，而是多口径并存：

- `llm_top_case_amount_cny`：LLM 抽取的案件金额。
- `regex_text_amount_max_cny`：全文正则匹配到的最大金额。
- `amount_master_cny`：综合后的主金额变量。

同时我们还保留：

- `amount_master_source`
- `amount_master_is_regex_fallback`
- `amount_llm_regex_text_conflict`

原因很简单：金额既是研究变量，也是数据质量变量。不能只看一个口径。

### 2.4 地区变量

原始 `region` 字段并不稳定，所以本轮主要依据法院名称映射省份，再进一步得到：

- `region_macro`：东部、中部、西部、东北
- `region_big4`：北京、上海、广东、浙江

这比直接相信原始空字段更可靠。

### 2.5 为什么用线性概率模型（LPM）

因变量 `contract_invalid` 只有 0 和 1。线性概率模型的好处是，系数可以直接解释成“概率变化的百分点”。

例如，系数 `0.0866` 可以理解为：在控制其他变量后，某个因素使合同非完全有效的概率上升了约 8.66 个百分点。

本轮使用的是 `HC1` 稳健标准误，这样能让标准误更稳一些，避免把结果看得过于乐观。

## 3. 数据和样本

主样本选择民商事案件，因为刑事样本里只要出现合同效力字段，几乎都已经是非完全有效，不适合直接和民商事案件放在一起解释。

样本概况如下：

- 全部样本：12,135
- 合同效力可用样本：5,714
- 民商事主样本：5,160
- 民商事主样本非完全有效率：42.1%
- 刑事参考样本：6,017，其中合同效力可用 528，非完全有效率 99.4%

一个很直观的理解是：刑事样本更像对照组，主问题还是应该放在民商事案件上。

## 4. 模型是怎么设定的

本轮不是只跑一个模型，而是用一组模型逐步加变量，看看结论稳不稳。

| 模型 | 作用 | 主要变量 |
|---|---|---|
| 基线模型 | 先看政策后是否更严格 | `post2021`、金额、金额质量、法院层级、案由 |
| 交易类型模型 | 看案件类型是否更重要 | 再加入 `transaction_type` |
| 交互模型 | 看政策对不同类型是否不同 | `post2021 * transaction_type` |
| 金额分位模型 | 看高金额是否不同 | `amount_quartile`、`q4_amount` |
| LLM / 正则金额模型 | 检查金额口径稳不稳 | `llm_top_case_amount_cny`、`regex_text_max` |
| 地区模型 | 看地区差异 | `region_big4`、`region_macro` |
| 严格因变量模型 | 看结论是否依赖口径 | `contract_invalid_strict` |
| 事件研究模型 | 看 2021 前后动态变化 | 年份虚拟变量 |

## 5. 核心结果

### 5.1 2021 政策后，合同非完全有效概率上升

这是本轮最稳定的结果。

| 模型 | `post2021` 系数 | 解释 |
|---|---:|---|
| 基线模型 | 0.0866 | 2021 后高约 8.7 个百分点 |
| 加入交易类型 | 0.1107 | 高约 11.1 个百分点 |
| 使用 LLM 金额 | 0.1122 | 结果仍然稳定 |
| 使用正则金额 | 0.1108 | 结果仍然稳定 |
| 严格因变量 | 0.1115 | 换口径后依然成立 |

这说明，2021 之后法院对虚拟货币相关合同的处理，确实更倾向于非完全有效。

### 5.2 交易类型比金额更关键

交易类型是解释力最强的一块。加入交易类型后，模型拟合明显变好，说明法院判断时看的不是“金额一个数”，而是“这个交易到底是什么类型”。

在描述统计里，不同类型的非完全有效率差异很大：

- `ICO/发币`：83.1%
- `投资/理财`：52.8%
- `交易/买卖`：46.7%
- `挖矿`：41.8%
- `借贷`：23.8%
- `技术服务`：9.6%

在回归里，以“借贷”为基准：

- `ICO/发币`：+0.550
- `投资/理财`：+0.214
- `交易/买卖`：+0.184
- `挖矿`：+0.128
- `技术服务`：-0.094

简单说，交易类型越接近高风险、强政策敏感的虚拟货币活动，法院认定非完全有效的概率通常越高。

### 5.3 金额要保留，但不要写成主结论

金额的结论并不单调。

描述统计里，按金额分位看：

- Q1 最低：44.1%
- Q2：40.9%
- Q3：43.7%
- Q4 最高：36.8%

这说明“金额越大，越容易无效”并不是一个稳定规律。

回归里也一样：

- `log_amount_master` 在基线模型里只有很小的负向关系。
- 加入交易类型后，`log_amount_master` 不再显著。
- `log_llm_case_amount` 也不显著。
- `log_regex_text_max` 显著为负。
- `post2021:q4_amount` 不显著。

所以，金额应该被写成控制变量、稳健性变量和数据质量变量，而不是本文的主结论。

### 5.4 地区差异存在，但不是最核心的政策异质性

地区有差异，但它更像“基础水平不同”，而不是“政策冲击在不同地区完全不同”。

描述统计上：

- Big4 地区非完全有效率：34.3%
- 非 Big4 地区非完全有效率：45.7%

宏观区域上：

- 东部：40.6%
- 中部：46.6%
- 西部：45.0%
- 东北：32.9%

回归里：

- `region_big4 = -0.0533`，说明 Big4 地区的非完全有效概率更低。
- `post2021:region_big4 = 0.0269`，但不显著，说明 2021 政策效应没有显示出明显的 Big4/非 Big4 差异。

因此，地区适合作为稳健性和背景差异来讲，不适合作为当前主识别变量。

### 5.5 事件研究显示 2021 后效果逐渐增强

事件研究以 2020 年为参考年。结果大致是：

- 2015：-0.315
- 2016：-0.111
- 2017：-0.011
- 2018：-0.055
- 2019：+0.042
- 2021：+0.050
- 2022：+0.119
- 2023：+0.130
- 2024：+0.171

这说明 2021 之后的确出现了更明显的上升趋势。

但要注意：早期年份样本很少，前趋势并不是完美平直，所以这里更适合写成“动态证据”，不要写成特别强的因果证明。

### 5.6 严格口径下，结论仍然成立

如果把因变量改成更严格的 `contract_invalid_strict`，`post2021` 还是显著为正，系数约 0.1115。

这说明本轮结论不是因为“合同效力口径松一点”才出现的。

## 6. 你应该怎样理解这些系数

这是初学者最容易混淆的地方。

- `0.0866` 不是“增加 8.66% 的相对比例”，而是“增加 8.66 个百分点”。
- `p < 0.001` 表示这个结果很难用随机波动解释，但不等于已经完全证明因果。
- `R-squared` 从 0.139 提高到 0.230，说明交易类型加入后，模型解释力明显增强。

所以可以把结论简单概括成：

1. 2021 后法院更容易把相关合同判成非完全有效。
2. 交易类型比金额更能解释这种判断。
3. 金额和地区有用，但更适合做辅助变量。

## 7. 可直接写进论文的主线

如果把这项研究写成论文，最稳的结构是：

1. 引言：说明虚拟货币纠纷为何值得研究。
2. 制度背景：解释 2021 政策节点。
3. 数据与变量：讲清合同效力、交易类型、金额、地区。
4. 描述统计：展示样本分布和基本差异。
5. 主回归：说明 2021 后非完全有效概率上升。
6. 异质性：重点讲交易类型差异。
7. 稳健性：金额三口径、严格因变量、地区控制、事件研究。
8. 讨论：法院判断为什么更像“按交易风险分类”，而不是单看金额大小。

## 8. 本轮结论

这轮最重要的判断是：

- 主结论应当放在“政策冲击 + 交易类型”上。
- 金额必须保留，但不要写成主结论。
- 地区可以讲，但更适合做稳健性和背景差异。
- 事件研究可以作为动态证据，但不要过度承诺因果。

换句话说，论文最核心的一句话可以先写成：

**2021 政策后，虚拟货币相关民商事裁判更容易认定合同非完全有效；这种变化主要由交易类型驱动，而不是单纯由金额大小决定。**

这句话目前和数据是匹配的。
